# 抖音本地生活卖车转化看板（Demo）

一个面向作品集展示的、**完全脱敏**的抖音本地生活卖车全链路转化分析看板。它通过模拟数据展示如何将订单、留资、销售跟进和最终成交串联为可复用的数据分析与经营复盘流程。

> **数据隐私说明：** 本仓库中的全部用户、订单、地区、直播间、产品线、转化率和金额均为脚本生成的模拟数据，不包含生产数据、内部渠道编码、真实门店/直播间、用户标识、订单标识、内部系统地址或访问凭据。

## 项目要解决的问题

在本地生活卖车场景中，内容渠道通常只能直接看到下单或留资，但销售跟进和最终成交发生在 CRM 或门店体系中。若数据分散，就难以回答：

- 哪类内容入口带来了更高质量的线索？
- 用户在哪个环节流失：留资、跟进、试驾还是成交？
- 哪个区域、直播间或产品线的转化效率更高？
- 渠道是否带来了新增成交、存量激活或辅助转化？

本 Demo 用一条用户级链路模拟回答这些问题：

`	
抖音内容触达 / 下单 → 留资 → 有效线索 → 销售机会创建 → 跟进 → 试驾 → 最终成交
`

## 核心功能

- 基于模拟订单、线索和成交记录构建用户级转化明细
- 按内容入口、直播间、区域、产品线和日期筛选
- 展示订单、有效线索、跟进、试驾、成交及转化率等核心指标
- 观察订单与成交的日度趋势，以及各维度的转化差异
- 下钻查看完全合成的用户级明细
- 通过固定随机种子生成数据，支持本地复现与校验
- 自动生成聚合统计和数据质量报告

## 本地运行

本项目不依赖第三方 Python 包。使用 Python 3.10+ 即可：

`ash
python scripts/run_demo.py
python -m http.server 8000
`

然后在浏览器访问 http://localhost:8000。


un_demo.py 会依次完成：

`	ext
生成模拟原始数据 → 生成用户级归因明细与聚合指标 → 数据质量校验
`

## 归因与指标口径

本仓库将“最终成交”划分为三类模拟归因：

| 归因类型 | 含义 |
| --- | --- |
| 新增获客 | 用户由内容入口带来新的销售机会并最终成交 |
| 存量激活 | 已存在销售机会的用户因内容触达重新进入跟进与成交流程 |
| 辅助转化 | 内容触达对后续成交起到辅助作用，但并非唯一触点 |

详细口径见 [docs/attribution-rules.md](docs/attribution-rules.md)。
