# 归因规则与指标口径

## 用户级链路

每条模拟记录对应一个内容渠道触达后的用户旅程：

`	ext
订单 → 留资 → 有效线索 → 销售机会创建 → 跟进 → 试驾 → 成交
`

各阶段均保留独立的业务发生日期。看板中可按订单日期筛选用户群，并在趋势图中分别按照对应阶段日期统计，避免将不同发生时间的指标误归于同一天。

## 归因类型

| 类型 | 判定逻辑 | 业务含义 |
| --- | --- | --- |
| 新增获客 | 由内容入口产生新销售机会，并完成最终成交 | 衡量渠道带来的新增成交贡献 |
| 存量激活 | 用户存在历史销售机会，内容触达后重新被跟进并成交 | 衡量内容对存量用户决策的促转作用 |
| 辅助转化 | 内容触达后在其他触点完成成交 | 衡量内容在多触点链路中的辅助价值 |

## 核心指标

| 指标 | 口径 |
| --- | --- |
| 支付订单 | order_status != 已退款 的订单数 |
| 留资用户 | lead_date 非空的用户数 |
| 有效线索 | is_qualified_lead = true 的用户数 |
| 已跟进销售机会 | opportunity_engaged_date 非空的用户数 |
| 试驾用户 | 	est_drive_date 非空的用户数 |
| 最终成交 | deal_date 非空的用户数 |
| 有效线索成交率 | 最终成交 / 有效线索 |
| 平均成交周期 | 销售机会创建日至最终成交日的平均天数 |

## 数据质量规则

1. 每个用户、订单和线索编号必须唯一。
2. 每个阶段日期必须不早于前一阶段日期。
3. 退款订单不进入后续销售漏斗。
4. 只有已成交记录才允许存在归因类型。
5. 输出文件不得包含生产标识、内部渠道编码、内部数据表名、令牌或真实个人信息。
